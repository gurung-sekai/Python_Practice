# Lovely Loveseats

A small Python project completed as part of my Python learning.

The program stores furniture descriptions and prices, calculates a customer's subtotal and sales tax, and prints a simple itemised receipt.

## Concepts Practised

- Variables
- Strings
- Numbers and arithmetic
- String concatenation
- Updating variable values
- Printing output with `print()`
- Using `\n` to format text across multiple lines

## Example Features

The program:

- Stores furniture descriptions and prices
- Adds purchased items to a customer's itemisation
- Calculates sales tax
- Calculates the final customer total
- Prints a formatted receipt to the terminal

## Running the Project

Run the Python file from the terminal:

```bash
python lovely_loveseats.py
